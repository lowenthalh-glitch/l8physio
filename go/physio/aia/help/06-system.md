# System administration

Sidebar: System opens the administration page. It has these tabs:

- Health - the health of the system's services.
- Security - sub-pages Users, Roles, Credentials and Events.
  - Users: the login accounts (clients and therapists get one automatically when they are created). Click Add to create an account, Edit to change it.
  - Roles: the built-in roles (administrator, therapist, client) and what each may see and do.
  - Credentials: stored connection details, for example the AI model and the Boostapp login.
  - Events: the security event log.
- Modules - the system's modules.
- Logs - the system log viewer.
- Data Import - import data from a file.

The System entry is shown to administrators only. Therapists and clients use their own portal, which shows only the pages they are allowed to see.
