# Exercises, Protocol Templates and Treatment Plans

## Create an exercise
1. Sidebar: Exercises, then Add.
2. "Exercise Details" tab: Name * (required), Categories, Description, Exercise Aim, Active.
3. "Progression / Regression" tab: pick a harder (Progression) and an easier (Regression) exercise, and an optional Rotation Group.
4. "Protocol Classification" tab: Joints, Posture Type, Load Type, Effort (RPE), Equipment, Muscle Group, Load Notes. The Workout Builder uses joints and posture to choose exercises.
5. "Default Parameters" tab: default sets, reps, hold seconds.
6. "Instructions & Media" tab: instructions, contraindications, an exercise image and a video path.
7. Click Save.

## Create a protocol template
1. Sidebar: Protocol Templates, then Add.
2. "Protocol Details" tab: Protocol Name * (required), Description, Goals, Active.
3. "Classification" tab: Joints, Categories and Posture the protocol applies to.
4. "Exercises" tab: add rows to the Protocol Exercises table. Each row has the order, circuit number and label, the exercise, sets, reps, hold, load type, weight, effort and notes.
5. Click Save.

## Create a treatment plan for a client
1. Sidebar: Treatment Plans, then Add.
2. "Plan Information" tab: Title * and Client * (required; click the field and pick the client). Optionally set Status (Draft, Active, Completed or Suspended), Start Date, End Date, Workout Volume and a Protocol.
3. "Clinical Details" tab: Goals, Description and Notes.
4. Click Save. To build the plan's exercises, open the plan (click its row) and use its Workout Plan editor.
