# Dashboard, Workout Builder and Boostapp Calendar

## Dashboard
Sidebar: Dashboard opens the head-therapist dashboard, an overview of clients and their recent activity.

## Workout Builder
Sidebar: Workout Builder. Use it to build a workout: choose the posture and joint, check the resolved protocol shown on the page, and click Build Workout to produce the workout. If no exercises match the chosen combination the page says so instead of showing a workout.

## Boostapp Calendar
Sidebar: Boostapp Calendar shows the events imported from the Boostapp booking system (title, time, coach, type, status, location, participants). The imported event data is read-only. To link an event to one of your clients, open the event and pick the client in the Linked Client field.
